## About CppProfiler

CppProfiler is a lightweight, header-based C++ profiling library designed for:

- **Minimal overhead**: Zero-cost abstraction when profiling is disabled
- **Easy integration**: Direct source inclusion or shared library linking
- **Cross-platform**: Windows, Linux (x86/ARM), and macOS support
- **Statistical analysis**: Repetition testing with average, variance, min, max metrics
- **Flexible reporting**: Console output and CSV export
